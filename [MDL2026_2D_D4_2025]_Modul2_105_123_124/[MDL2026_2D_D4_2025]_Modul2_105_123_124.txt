---

## 1. What is Graph Isomorphism?

Two simple graphs $G_1 = (V_1, E_1)$ and $G_2 = (V_2, E_2)$ are **isomorphic** if they have the exact same structural layout, regardless of how their vertices are drawn or labeled.

Formally, there must exist a **bijective (one-to-one and onto) function** $f: V_1 \to V_2$ such that vertices $a$ and $b$ are adjacent in $G_1$ if and only if $f(a)$ and $f(b)$ are adjacent in $G_2$.

---

## 2. Graph Invariants (Testing Non-Isomorphism)

A **graph invariant** is a property preserved by isomorphism. If two graphs differ in any of these properties, they **cannot** be isomorphic:

1. **Number of Vertices ($\vert{}V\vert{}$):** Both graphs must have equal numbers of nodes.


2. **Number of Edges ($\vert{}E\vert{}$):** Both graphs must have equal numbers of edges.


3. **Degree Sequence:** The multiset of vertex degrees must match (e.g., both graphs must have four degree-2 vertices and four degree-3 vertices).


4. **Neighbor Substructure:** Adjacent vertices must preserve degree relationships (e.g., if a degree-2 vertex in $G_1$ is connected to two degree-3 vertices, its mapped image in $G_2$ must also be connected to two degree-3 vertices).



---

## 3. Python Code for Graph Isomorphism (NetworkX)

In Python, the `networkx` library provides built-in functions to verify if two graphs are isomorphic and extract the vertex mapping function $f$:

```python
import networkx as nx

# 1. Create Graph G (Figure 8 top)
G = nx.Graph()
G.add_edges_from([("u1", "u2"), ("u1", "u3"), ("u2", "u4"), ("u3", "u4")])

# 2. Create Graph H (Figure 8 bottom)
H = nx.Graph()
H.add_edges_from([("v1", "v3"), ("v1", "v4"), ("v2", "v3"), ("v2", "v4")])

# 3. Check Isomorphism
is_iso = nx.is_isomorphic(G, H)
print(f"Are G and H isomorphic? {is_iso}")

# 4. Get the Vertex Mapping Function f: V(G) -> V(H)
if is_iso:
    matcher = nx.isomorphism.GraphMatcher(G, H)
    mapping = matcher.mapping
    print("\nVertex Mapping f:")
    for g_node, h_node in mapping.items():
        print(f"  f({g_node}) = {h_node}")

```

## 1. Graf tidak berarah (Undirected Graph)

Teorema Handshaking menyatakan bahwa jumlah seluruh derajat simpul sama dengan dua kali jumlah sisi.

\\[ \sum\_{v\in V}\deg(v)=2|E| \\]

Kode kamu sudah tepat:

```

```

Alasannya: setiap sisi berkontribusi sebanyak dua terhadap jumlah derajat, yaitu satu pada setiap ujungnya. Sisi gelang (self-loop) juga dihitung dua kali dalam derajat simpul.

## 2. Graf berarah (Directed Graph)

Pada graf berarah, setiap simpul memiliki dua jenis derajat:

- In-degree: jumlah sisi yang masuk ke simpul.
- Out-degree: jumlah sisi yang keluar dari simpul.

Teorema Handshaking untuk graf berarah menyatakan:

\\[ \sum\_{v\in V}\deg^-(v)=|E| \\]

\\[ \sum\_{v\in V}\deg^+(v)=|E| \\]

Artinya, jumlah seluruh in-degree dan jumlah seluruh out-degree masing-masing sama dengan jumlah sisi.

Contoh kode menggunakan NetworkX:

```
# Handshaking Theorem (Graf Berarah)total_in_degree = sum(dict(G.in_degree()).values())total_out_degree = sum(dict(G.out_degree()).values())jumlah_sisi = G.number_of_edges()print("\nVerifikasi Handshaking Theorem (Graf Berarah):")print(f"Total in-degree = {total_in_degree}")print(f"Total out-degree = {total_out_degree}")print(f"Jumlah sisi = {jumlah_sisi}")if total_in_degree == jumlah_sisi and total_out_degree == jumlah_sisi:    print("Status: TERVERIFIKASI (Handshaking Theorem terbukti benar)")else:    print("Status: TIDAK TERVERIFIKASI")
```

Ganti `G` dengan nama variabel graf berarah yang kamu gunakan.

## 3. Perbedaan singkat

| Aspek           | Graf tidak berarah                             | Graf berarah                                                                 |
| --------------- | ---------------------------------------------- | ---------------------------------------------------------------------------- |
| Derajat         | Satu jenis derajat                             | In-degree dan out-degree                                                     |
| Rumus           | \\(\sum \deg(v)=2\|E\|\\)                      | \\(\sum \deg^-(v)=\|E\|\\) dan \\(\sum \deg^+(v)=\|E\|\\)                    |
| Kode verifikasi | Total derajat dibandingkan dengan \\(2\|E\|\\) | Total in-degree dan out-degree masing-masing dibandingkan dengan \\(\|E\|\\) |

Kesimpulan: kode awalmu tidak perlu diubah untuk graf tidak berarah. Untuk graf berarah, gunakan kode kedua agar kedua jenis derajat diverifikasi secara terpisah. Pastikan juga `degrees` dihitung dari graf yang sama dengan `G3` agar hasil verifikasinya valid.

```python
    print(f"{node}: {neighbors}")
```

Hasil yang diharapkan:
```
Processor: ['Memory', 'Storage']
Memory: ['Processor']
Storage: ['Network Interface']
Network Interface: ['Processor']
```

**Bug 2: Isomorfisme pasti `False` karena G4 punya 8 simpul.**
`G4.add_nodes_from(nodes)` menambahkan empat nama komponen, lalu `add_edges_from` menambahkan lagi a, b, c, d. Jadinya G4 berisi 8 simpul, sedangkan G hanya 4, sehingga `is_isomorphic` otomatis `False` karena jumlah simpul berbeda, bukan karena strukturnya. Hapus baris `G4.add_nodes_from(nodes)`.

Setelah diperbaiki pun, G4 memang tidak isomorfik dengan G. Di G4, simpul c punya in-degree 3, sedangkan di G in-degree maksimumnya 2. [High confidence, dari hitungan manual.] Hasil `False` jadi benar tapi hanya menunjukkan satu sisi, padahal soal meminta "identifikasi isomorfisme". Tambahkan satu graf yang isomorfik supaya pemahamannya terlihat:

```python
#Isomorfisme
# G4: BUKAN isomorfik (in-degree simpul c = 3, sedangkan G maksimal 2)
G4 = nx.DiGraph()
G4.add_edges_from([('a', 'b'), ('a', 'c'), ('b', 'c'), ('d', 'c'), ('d', 'a')])

# G5: isomorfik (struktur sama, hanya nama simpul berbeda)
G5 = nx.DiGraph()
G5.add_edges_from([('a', 'b'), ('a', 'c'), ('b', 'a'), ('c', 'd'), ('d', 'a')])

print("\nIsomorfisme:")
print(f"G isomorfik dengan G4: {nx.is_isomorphic(G, G4)}")
print(f"G isomorfik dengan G5: {nx.is_isomorphic(G, G5)}")

matcher = nx.isomorphism.DiGraphMatcher(G, G5)
if matcher.is_isomorphic():
    print("Pemetaan simpul G -> G5:", matcher.mapping)
```

Hasil yang diharapkan: `False` untuk G4, `True` untuk G5, dengan pemetaan Processor→a, Memory→b, Storage→c, Network Interface→d.
